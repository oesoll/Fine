# 홈 배경 바꾸기

홈 오른쪽 아래 **배경** 또는 **View → 홈 배경 고르기…** (`⌘⇧B`)에서 고른다.
화이트 모드와 다크 모드의 선택은 각각 저장되며, 앱을 다시 열어도 유지된다.

- **풍경 15개**: 안개 숲, 오로라 피오르, 알프스의 새벽, 바다의 노을, 밤의 해안, 사막의 밤, 등불 호수, 교토의 황혼, 비 내리는 도쿄, 폭풍의 평원, 깊은 바다 산호초, 떠오르는 지구, 마린 드라이브, 타지마할의 새벽, 바라나시의 강가. 원본을 상단에 배치하고 아래를 테마 색으로 페이드한다.
- **작은 오로라**: 원본 전체를 작은 2:1 창으로 인사말과 입력창 사이에 보여 준다.
- **내 사진**: 기존 사진을 사용한다. **사진 파일 고르기…**로 해당 모드의 사진을 교체한다.
- **단색**: 풍경 없이 테마의 바탕만 쓴다.

홈에서 `⌘← / ⌘→`를 짧게 누르면 배경을 순환한다. 약 0.5초 이상 누르면 선택
모달이 열리며, 배경이 먼저 바뀌지는 않는다. 사진이 없으면 순환에서 사진을 건너뛴다.
`⌘↑ / ⌘↓`는 이전·다음 대화로 이동한다. 터미널의 `⌘← / ⌘→`는 그대로다.

모달에서는 방향키로 배경을 미리 보고 Return 또는 완료로 닫는다. Escape로도 닫을 수 있으며, 입력 포커스는 메시지 칸으로 돌아간다. 화이트/다크를 바꾸면 앱도 해당 모드로 전환되어 고른 배경을 즉시 확인할 수 있다.

연속 전환은 현재 보이는 장면에서 이어지며, 글자색은 글자 뒤의 실제 배경 밝기를 따른다. 동작 줄이기 설정에서는 전환 효과와 풍경 재생을 줄인다.

## 사진 파일

기존 `~/.fine/home-scene.{png,jpg,jpeg,heic,webp}`는 다크 모드 사진으로 유지된다.
화이트 모드 사진은 `~/.fine/home-scene-light.*`에 따로 저장한다. 화이트 전용 사진이
없으면 기존 사진을 함께 선택할 수 있다. 고른 파일을 읽고 이미지로 검증한 다음
원자적으로 저장하므로, 잘못된 파일을 골라도 기존 사진을 먼저 지우지 않는다.

그림은 앱 번들·저장소에 넣지 않는다. 사용자 이미지가 없으면 다크 사진 모드는
번들의 `HomeScene` 또는 절차적 밤하늘을 표시한다. ASCII 원본·렌더러·MIT 라이선스는
앱에 포함되어 인터넷 없이 동작한다.
